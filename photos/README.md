# 写真フォルダ

ここに写真を入れて push すると、自動で縮小・WebP化・メタデータ削除をしてサイトに並ぶ。
GitHub の Web 画面で、フォルダを開いて「Add file → Upload files」にドラッグ＆ドロップするだけでもいい。

## フォルダの分け方：1つの旅・テーマ = 1つのロール

```
photos/
  tokyo/                   ← 年のないフォルダは「いつもの」ロール（いちばん上に並ぶ）
  2023-08-setouchi/        ← 「年-月-名前」。新しい順に並ぶ（月は省略して 2023-setouchi でもいい）
    roll.json              ← 任意：日本語のロール名やひとこと
    IMG_1234.jpg
  2024-03-italy/
  2026-03-paris/
  2026-10-kenya/
  covers/
    2026.jpg               ← 2026年号の表紙（ファイル名は 2026 / 2025 / pre）
```

- **フォルダ名は半角の英数字とハイフンだけ**（URL になるため）。日本語の名前は `roll.json` で付ける：

  ```json
  { "label": "瀬戸内", "note": "高校2年の旅", "camera": "Canon EOS R" }
  ```

  `roll.json` がなければ、フォルダ名の英語部分がそのまま名前になる（`2024-03-italy` → Italy）。
- 写真の並び順はファイル名順。カメラの番号（IMG_1234）のままなら撮った順になる。
- ファイル名をタイトルにしたいときは `01-mita-morning.jpg` のように（先頭の数字は並び順、- は空白になる）。
- 撮影日・レンズ・F値は、写真に記録されていれば自動で表示される。
- サイトでは：ハブの暗室に新しいロール4本、`/photos/` に全ロールが年ごとに並ぶ。

## 入れる前に

- **撮ったままのサイズは入らない**（GitHub の Web 画面は 1 ファイル 25MB まで）。
  Mac の Finder で写真を選んで右クリック →「クイックアクション」→「イメージを変換」→ JPEG・サイズ「大」で縮小してから入れる。
- **位置情報（GPS）が入った写真は入れないこと。** このリポジトリは誰でも見られるので、元の写真もそのまま公開される。
  入っていた場合はサイトの更新が止まり、エラーで知らせる。
- 友だちの顔がはっきり写っている写真は、載せていいか本人に一言確認しておくと安心。
