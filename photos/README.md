# 写真フォルダ

ここに写真を入れて push すると、自動で縮小・WebP化・メタデータ削除をしてサイトに並ぶ。
GitHub の Web 画面で、フォルダを開いて「Add file → Upload files」にドラッグ＆ドロップするだけでもいい。

```
photos/
  01-tokyo/        ← 暗室のロール。数字は並び順、その後ろがロール名（Tokyo）
    01-mita-morning.jpg   ← ファイル名がタイトルになる（先頭の数字は並び順、- は空白に）
    02.jpg                ← タイトルなしでもいい
    roll.json             ← 任意: {"label": "Tokyo", "camera": "Canon EOS R"}
  02-paris/
  03-nairobi/
  covers/
    2026.jpg       ← 2026年号の表紙（ファイル名は 2026 / 2025 / pre）
```

- 撮影日・レンズ・F値は、写真に記録されていれば自動で表示される（オールドレンズは記録されないことが多い）
- **位置情報（GPS）が入った写真はアップしないこと。** このリポジトリは誰でも見られるので、元の写真もそのまま公開される。
  入っていた場合はサイトの更新が止まり、エラーで知らせる。
  - iPhone: 共有 → オプション → 「位置情報」をオフにしてから保存
  - Mac の写真アプリ: 書き出し時に「位置情報を含める」をオフ
- 1枚 5MB 以下くらい（長辺 2500px 程度）に書き出してから入れると軽い
