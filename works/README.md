# 作品の画像フォルダ

作品ごとにフォルダを作って画像を入れると、サイトの Works に並び、タップすると全画面で1枚ずつ見られる。

```
works/
  aogumi-pamphlet/     ← 運動会 青組パンフレット（src/data/site.ts の works で images: 'aogumi-pamphlet'）
    01-cover.jpg       ← ファイル名順に並ぶ。1枚目が表紙として使われる
    02.jpg
```

- 写真フォルダと同じく、縮小・WebP化・メタデータ削除は自動。位置情報入りの画像は公開が止まる。
- パンフレットは PDF ではなく、ページごとの JPEG / PNG で入れる（Mac のプレビューで「書き出す」→ JPEG）。
- 友だちの名前や顔が載っているページは、公開してよいか確認しておくと安心。
